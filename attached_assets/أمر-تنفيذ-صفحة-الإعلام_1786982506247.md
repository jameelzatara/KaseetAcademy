**⚠️ ملاحظة اتّساق واحدة:** الهيرو يقول **8 مشاريع تطبيقية**، والمحفظة **12 مخرجاً**. الرقمان لا يتناقضان (المشروع التطبيقي واجب مُقيَّم، والمخرَج قطعة في المحفظة) لكنّ الزائر سيحسب. **الأنسب:** يُبدَّل عدّاد الهيرو إلى **«12 مخرجاً في محفظتك»** ويُنقل «8 مشاريع تطبيقية» إلى قسم المنهج حيث موضعه الطبيعي.


# ٥ · قسم «الاستشارة التعليمية» — إعادة تصميم

## المشكلة

بطاقة واحدة بمستشارة واحدة، وفراغ داخلي يبلغ ثلاثة أضعاف ما يحتاجه محتواها. والنمط الحضوري غائب تماماً من الصفحة رغم أنّه أحد نمطَي التقديم.

## البنية الجديدة

**بطاقة واحدة تضمّ المستشارتين** — عمودان بفاصل رأسي `--card-line`، بعرض أقصى **720px**.

```
┌─────────────────────────────────────────────────┐
│   [صورة 64px]  آية القماز        │  [صورة 64px]  ياقوت خشاشنة        │
│   المستشارة التعليمية — كاسيت أكاديمي │  المستشارة التعليمية — كاسيت أكاديمي │
│   📍 حضوري · عمّان                │  📶 مباشر تفاعلي (Online LIVE)     │
│   [ تحدّث مع آية — واتساب ]        │  [ تحدّث مع ياقوت — واتساب ]        │
└─────────────────────────────────────────────────┘
```

| العنصر | المواصفة |
|---|---|
| الصورة | دائرية 64px · حدّ `--card-line` |
| الاسم | **بالكامل** — «آية القماز» · «ياقوت خشاشنة» ⛔ لا اسم أوّل وحده |
| الدور | المستشارة التعليمية — كاسيت أكاديمي · `--t3` |
| شارة آية | أيقونة `map-pin` + «حضوري · عمّان» |
| شارة ياقوت | أيقونة `wifi` + «مباشر تفاعلي (Online LIVE)» |
| الزرّان | **مفرّغان بحدّ أخضر** ⛔ لا مملوءان — الأخضر المملوء يغلب زرّ الدفع |
| الأيقونات | `lucide-react` · 16px · `--t4` |

```
⛔ احذف الفراغ الداخلي الضخم — padding: 28px 32px
⛔ عنوان القسم بلون --t1 واحد بلا تمييز ذهبي
⛔ لا أرقام هواتف مطبوعة داخل الأزرار
⛔ «متاحة الآن» — تُربَط بالدوام (السبت–الخميس · 10:00–20:00) أو تُحذف
```

**على الموبايل:** العمودان يتراكمان، والفاصل الرأسي يصبح أفقياً.

## لماذا الخبراء بين المنهج والسعر

المنهج يخلق السؤال «مَن يُدرّسني هذا كلّه؟» — فيصل الجواب وهو في ذهن الزائر، ثمّ السعر مباشرةً. أي أنّ الثقة تبلغ أعلى نقطة قبل ظهور الرقم. ولو تقدّم القسم إلى أوّل الصفحة، وصل قبل أن يعرف الزائر ما المنهج، فمرّ بلا وزن.

## 🔴 شريط CTA اللاصق صار إلزامياً

نقل الأسئلة إلى آخر الصفحة يجعل آخر ما يقرأه الزائر **سؤالاً لا دعوة**. بلا الشريط اللاصق تنتهي الصفحة بلا أيّ زرّ أمامه.

```
موبايل فقط · يظهر بعد القسم 02 · السعر + زرّ الدفع
يختفي عند القسم 07
```

# ٩ · اختبارات القبول

```bash
# 1 · الخطوط — لا نتيجة
grep -rn "googleapis\|gstatic\|@import url" src/
grep -rn "font-family" src/components/ src/layouts/

# 2 · الأيقونات — لا نتيجة

# 3 · المصطلحات — لا نتيجة

# 5 · الذهبي — الأزرار والأسعار فقط
grep -rn "#FFC107" src/components/masterclass/
```

**اختبار القالب:** غيّر لون شارة القسم في `MasterclassLayout` **مرّة واحدة** → تتغيّر في الصفحات الثلاث. احتجت أكثر من ملفّ ← نُسخ التصميم ولم يوحَّد.

**اختبار الذهبي:** أوقف `--gold` مؤقّتاً → يختفي الأسعار وأزرار الفعل فقط. اختفى غيرهما ← الذهبي ما زال مستهلَكاً.
