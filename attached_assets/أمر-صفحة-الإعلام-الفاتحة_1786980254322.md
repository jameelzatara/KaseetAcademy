# ١ · الوضع الفاتح — على مستوى الصفحة لا البلوك

```ts
// masterclasses.ts
theme: 'dark' | 'paper'

voice → 'dark'    khataba → 'dark'    elam → 'paper'
```

كلّ بلوك يقرأ `theme` من البيانات ويقلب توكنزه.
⛔ **لا نسخة ثانية من `MasterclassLayout`** — وإلّا عدنا إلى ثلاث صفحات منفصلة.
⛔ **ولا `theme` على البلوكات فرادى** — الصفحة كلّها فاتحة أو كلّها داكنة.

## خريطة الألوان

```css
[data-theme="paper"] {
  --canvas:     #FAF7F1;
  --card:       rgba(255,255,255,.66);
  --card-hi:    rgba(255,255,255,.86);
  --card-line:  rgba(122,88,26,.12);

  --t1: #201A12;   --t2: #46403A;
  --t3: #6E665C;   --t4: #948B7E;

  --gold-ink:   #8A6200;   /* كلّ ذهبي نصّي */
  --gold:       #FFC107;   /* الأزرار المملوءة وحدها */
  --on-gold:    #201A12;
  --teal:       #14606A;
  --green:      #157A43;
  --dot:        rgba(122,88,26,.14);
}
```

**⛔ القاعدة الحاكمة:** على الفاتح، الذهبي `#FFC107` **لا يُستخدم نصّاً ولا حدّاً ولا أيقونة** — للأزرار المملوءة فقط. أيّ ذهبي آخر `--gold-ink`.

## النقش

```css
[data-theme="paper"] .mc-page::before {
  content: '';
  position: fixed;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  background-image:
    radial-gradient(var(--dot) 1.3px, transparent 1.3px),
    radial-gradient(var(--dot) 1.3px, transparent 1.3px);
  background-size: 24px 24px;
  background-position: 0 0, 12px 12px;
  -webkit-mask-image: radial-gradient(120% 70% at 50% 0%, #000 40%, transparent 92%);
          mask-image: radial-gradient(120% 70% at 50% 0%, #000 40%, transparent 92%);
}
```

النقش **على الصفحة لا على القسم** — فتختفي حدود الأقسام ولا يبقى فاصل حادّ في أيّ موضع.
⛔ **ولا تدرّجات فاصلة بين الأقسام** — لا حاجة لها بعد توحيد الخلفية.

# ٢ · البلوك 02 — المخرجات الأربعة

يبقى بنفس تصميم البطاقات القائم، بأربعة إصلاحات:

```
1. الرقم أصغر من عنوان البطاقة — لا أكبر منه
   حجم الرقم 22px · وزن 500 · لون --t4
   عنوان البطاقة 19px · وزن 700 · لون --t1
2. احذف الخطّ الذهبي القصير تحت الرقم
3. عنوان القسم بلون --t1 واحد — احذف تمييز «ستُحقّقه» الذهبي
4. الشارة: خلفية rgba(122,88,26,.08) + نصّ --t2 + نقطة --teal
   ⛔ لا شارة ذهبية مملوءة
```

**السبب في 1:** الرقم ترقيم لا معلومة. حين يسود على العنوان تُقرأ البطاقة كبند في قائمة لا كفائدة.

⛔ «شهادة معتمدة من وجيز»

# ٣ · البلوك 04 — المحفظة · صفوف

**⛔ صفوف لا بطاقات.** ثلاثة عشر عنصراً لا تُقرأ كشبكة: الرقم الكبير يغلب المحتوى، و13 لا تنقسم على الشبكة، والصفّ النجمي يقع في موضع عشوائي حسب العرض. الجرد بنيته الطبيعية صفوف تُمسح عمودياً بنظرة.

## النصوص

```
الشارة:      محفظة الأعمال
العنوان:     تتخرّج بشريط أعمال لا بشهادة
السطر:      الجهة الإعلامية لا تسأل عن شهادتك، بل تطلب أن ترى تسجيلاً لك
            على الشاشة. هذه محفظتك عند إتمام المسار.
رأس الجدول:  محفظتك الإعلامية · 12 مخرجاً + مشروع التخرّج
شارة العدد:  13 مخرجاً
التنويه:     الأعمال المميّزة بالذهبي هي الأكثر أثراً في السوق: المقابلة
            تُثبت قدرتك على إدارة ضيف، وشريط الأعمال هو ما تُقيَّم به
            قبل أن تُقابَل.
```

## بنية الصفّ — أربعة أعمدة

```
[ الرقم ]  [ اسم المخرَج — يمتدّ ]  [ الوسم ]  [ النوع ]
   40px            1fr                 88px      72px
```

```css
.pf-row {
  display: grid;
  grid-template-columns: 40px minmax(0,1fr) 88px 72px;
  align-items: center;
  gap: 16px;
  padding: 14px 20px;
  border-bottom: 1px solid var(--card-line);
}
.pf-row:last-child { border-bottom: 0; }
```

⛔ **بلا موجات صوتية** — أكثر مخرجات الإعلام فيديو، والموجة تَعِد بصوت.
✅ **عمود «النوع»** بدلها: أيقونة `lucide-react` + كلمة.
`فيديو → video` · `صوت → audio-lines` · `وثيقة → file-text` · `إنتاج كامل → clapperboard`
الأيقونة 16px بلون `--t4`.

## الصفوف المميَّزة — ثلاثة فقط

```css
.pf-row--star {
  background: rgba(138,98,0,.055);
  border-inline-start: 2px solid var(--gold-ink);
  border-radius: 0;
}
.pf-row--star .pf-name { color: var(--gold-ink); font-weight: 700; }
```

**06 · 11 · ★ حصراً.** ⛔ ورابع يُلغي معنى التمييز.
⛔ **`border-radius: 0` على الحدّ الجانبي** — الحدود أحادية الجهة لا تُدوَّر.
