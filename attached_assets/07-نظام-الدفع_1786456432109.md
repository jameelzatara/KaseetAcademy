## ⚠️ ثلاثة قيود يجب استيعابها قبل البناء

### 1.1 · ✅ محسوم — التحصيل بالدولار الأمريكي

**`JOD` غير مدعوم في الحساب. كلّ التحصيل بالدولار الأمريكي (`usd`) بلا استثناء.**

| البرنامج | يُعرَض | يُحصَّل |
|---|---|---|
| أساسيات — حضوري | **218 ديناراً** | **$307** |
| أساسيات — مباشر تفاعلي | **$150** | **$150** |
| ماستركلاس — حضوري | **550 ديناراً** | **$775** |
| ماستركلاس — مباشر تفاعلي | **$750** | **$750** |

## ⛔ البيان الإلزامي — لا يُحذف ولا يُصغَّر

يظهر **فوق زرّ الدفع مباشرة** في كلّ عملية سعرها معروض بالدينار:

**⛔ لماذا هذا البيان إلزامي:** الزبون الذي يرى «550 ديناراً» ثمّ يجد في كشف حسابه ما يعادل 565 بعد عمولة بنكه، **يعتبرها خديعة ويطلب استرداداً** — أو يفتح نزاعاً بنكياً. وسطر واحد صريح يمنع ذلك كلّه.

**ويظهر البيان كذلك في:**
- بريد التأكيد
- شاشة النجاح
- بند «الأسعار والدفع» في الشروط والأحكام

### 1.1أ · تبسيط تقني مهمّ

بما أنّ التحصيل بالدولار دائماً:

**⛔ لا حاجة لدالّة عملات متعدّدة في طبقة الدفع.** العرض متعدّد العملات (للتسويق)، أمّا التحصيل فبعملة واحدة:

```ts
export const CHARGE_CURRENCY = 'usd';        // ثابت
export const CHARGE_DECIMALS = 2;            // الدولار خانتان

export function toMinorUSD(amountUSD: number) {
  return Math.round(amountUSD * 100);
}

/** يحوّل السعر المعروض بالدينار إلى مبلغ التحصيل بالدولار */
export function jodToChargeUSD(amountJOD: number) {
  return Math.ceil(amountJOD * FX.rates.USD);   // تقريب لأعلى — لا خسارة كسور
}
```

**✅ وهذا يُلغي خطر الخانات الثلاث للدينار** الذي كان يمكن أن يُحصّل عُشر المبلغ أو عشرة أضعافه. **الدولار خانتان فقط، وهذا كلّ ما نحتاجه.**

**⛔ ومع ذلك: لا تُمرّر `jod` إلى سترايب في أيّ استدعاء** — لا في `price_data.currency` ولا في أيّ موضع آخر.

### 1.2 · الرسوم — احسبها في تسعيرك

سترايب بريطانيا: **~2.5% + £0.20** للبطاقات الأوروبية · **~3.25% + £0.20** للبطاقات الدولية (وكلّ بطاقة عربية دولية) · **+2%** تحويل عملة عند التحصيل بغير الجنيه.

| البرنامج | السعر | ≈ بالدولار | الرسوم التقديرية | الصافي |
|---|---|---|---|---|
| أساسيات — حضوري | 218 د.أ | $307 | **~$16** | ~$291 |
| أساسيات — مباشر تفاعلي | $150 | $150 | **~$8** | ~$142 |
| ماستركلاس — حضوري | 550 د.أ | $775 | **~$41** | ~$734 |
| ماستركلاس — مباشر تفاعلي | $750 | $750 | **~$40** | ~$710 |

**الإجمالي التقريبي: 5.3% – 5.5%** من كلّ عملية.
**⛔ ولا تُحمّل الرسوم على الزبون** — تُستوعَب في السعر.

### 1.3 · الفاتورة تصدر باسم الكيان البريطاني

**وهذا يصطدم بموضعين:**

**أ · الشروط والأحكام** تنصّ على أنّ الكيان أردني والاختصاص لمحاكم عمّان. **يجب تعديلها** لتذكر الكيانين: الكيان الأردني مقدّم الخدمة، والكيان البريطاني معالج المدفوعات.

**ب · الأفواج المؤسسية** — الشركة التي تشتري فوجاً بـ9,500 دينار تحتاج **فاتورة أردنية بالرقم الضريبي `200189476`**، والفاتورة البريطانية لا تنفعها محاسبياً.

**⛔ ولذلك: الفوج المؤسسي لا يمرّ عبر سترايب.** زرّه يفتح واتساب لعرض سعر وفاتورة أردنية يدوية.

# القسم 2 · طبقة `PaymentProvider` — إلزامية

**⛔ لا يستدعي أيّ مكوّن واجهة سترايب مباشرة.**

```
صفحة الدفع  →  PaymentProvider  →  { stripe | hyperpay | manual }
```

```ts
// server/payments/types.ts
export interface CheckoutInput {
  orderId: string;
  itemName: string;          // «أساسيات التعليق والأداء الصوتي — حضوري»
  itemDesc: string;          // «الدفعة #137 · تبدأ 10 أغسطس · رنا العزام»
  amountMinor: number;       // بأصغر وحدة
  currency: string;          // 'usd' | 'jod' | 'sar' …
  customer: { firstName:string; lastName:string; email?:string; phone:string; country:string };
  metadata: Record<string,string>;
  successUrl: string;
  cancelUrl: string;
}

export interface PaymentProvider {
  id: 'stripe' | 'hyperpay' | 'manual';
  createCheckout(input: CheckoutInput): Promise<{ url: string; sessionId: string }>;
  verifyWebhook(rawBody: Buffer, signature: string): Promise<WebhookEvent>;
}
```

**الفائدة:** إضافة HyperPay لاحقاً = ملفّ واحد جديد، لا إعادة بناء.

## 3.1 · فصل العرض عن التحصيل

## 3.2 · مصدر الحقيقة: الدينار

```ts
// config/currency.ts

  base: 'JOD',
  updated: '2026-08-01',        // يُحدَّث يدوياً كلّ ربع سنة

```

**⛔ لا أسعار صرف حيّة.** تُغيّر السعر يومياً وتُنتج خلافاً عند الدفع.

## 3.3 · قاعدة التقريب

```ts
jodToChargeUSD(550) → Math.ceil(550 × 1.41) = 776
```

**تقريب لأعلى دائماً** — الكسور تُخصم من هامشك لا من الزبون.
**والرقم المعروض في البيان الإلزامي هو الرقم المُحصَّل نفسه** — لا رقم تقريبي مختلف.

## 3.4 · ⛔ خطأ يجب تجنّبه

```ts
unit_amount: toMinorUSD(776)      // ✅ 77600
unit_amount: 776                  // ❌ يُحصّل $7.76
unit_amount: toMinor(550,'jod')   // ❌ عملة غير مدعوعة أصلاً
```

**اختبر بعملية حقيقية بمبلغ صغير قبل الإطلاق.**

# القسم 5 · حجز المقعد — منع الحجز المزدوج

**المشكلة:** بين إنشاء الجلسة وإتمام الدفع تمرّ دقائق، وقد يحجز غيرك آخر مقعد.

## الحلّ: حجز مؤقّت بمهلة

```ts
// قبل إنشاء جلسة الدفع
const cohort = await getCohort(cohortId);
const held = await countActiveHolds(cohortId);          // حجوزات لم تنتهِ مهلتها
if (cohort.remaining - held <= 0) {
  return { error: 'CAP_REACHED',
           msg: 'نفدت مقاعد هذه الدفعة. هذه أقرب دفعة متاحة:', alternative: nextCohort };
}
await createHold({ cohortId, orderId, expiresAt: Date.now() + 30*60*1000 });
```

| الحدث | ما يحدث للحجز |
|---|---|
| نجح الدفع | يتحوّل إلى **مقعد مؤكَّد** ويُنقص `remaining` |
| ألغى المستخدم | يُحرَّر فوراً |
| انتهت المهلة (30 دقيقة) | يُحرَّر تلقائياً بمهمّة دورية |

**⛔ ولا تُنقص `remaining` عند إنشاء الجلسة** — فقط عند تأكيد الـWebhook.

# القسم 6 · الـWebhook — هو وحده يؤكّد الدفع

## 6.1 · ⛔ لماذا لا يكفي `success_url`

الزائر يستطيع فتح رابط النجاح يدوياً بلا دفع. **والـ`success_url` يعرض «جارٍ التأكيد…» فقط**، ولا يمنح مقعداً.

## 6.2 · التنفيذ

```ts
// server/webhooks/stripe.ts  —  raw body إلزامي، لا JSON parser
export async function stripeWebhook(req, res) {
  let event;
  try {
    event = stripe.webhooks.constructEvent(
      req.rawBody, req.headers['stripe-signature'], process.env.STRIPE_WEBHOOK_SECRET
    );
  } catch (err) {
    return res.status(400).send(`Webhook Error: ${err.message}`);
  }

  if (event.type === 'checkout.session.completed') {
    const s = event.data.object;

    // ① منع التكرار — سترايب قد يُعيد الإرسال
    if (await orderExists(s.id)) return res.json({ received: true });

    // ② أنشئ الطلب
    const order = await createOrder({
      sessionId: s.id,
      paymentIntent: s.payment_intent,
      ...s.metadata,
      amountPaidMinor: s.amount_total,
      currency: s.currency,
      status: s.metadata.plan === 'full' ? 'paid_full' : 'paid_first',
    });

    // ③ ثبّت المقعد وأنقص المتبقّي
    await confirmHold(order.id);
    await decrementSeat(s.metadata.cohortId);

    // ④ الإشعارات
    await sendConfirmationEmail(order);
    await sendWhatsAppConfirmation(order);
    await notifyInternal(order);              // info@kaseet.com
  }

  res.json({ received: true });
}
```

## 6.3 · أحداث أخرى تُعالَج

| الحدث | الإجراء |
|---|---|
| `checkout.session.expired` | حرّر الحجز |
| `charge.refunded` | حدّث الطلب إلى `refunded` وأعِد المقعد |
| `charge.dispute.created` | **أشعِر فوراً** — نزاع بنكي يحتاج ردّاً خلال أيام |

**⛔ والـWebhook يجب أن يستقبل `raw body`** — أيّ middleware يحلّل JSON قبله يكسر التحقّق من التوقيع.

# القسم 7 · التقسيط — ✅ محسوم

## القاعدة

| النمط | الدفع |
|---|---|
| **مباشر تفاعلي (Online LIVE)** | **دفعة واحدة كاملة** — لا تقسيط |
| **حضوري** | **50 ديناراً حجز مقعد** إلكترونياً + دفعتان أثناء الدورة |

**⛔ لا خيار تقسيط في النمط المباشر التفاعلي** — لا تعرض المنتقي أصلاً، لا تعرضه معطّلاً.

## 7.1 · جدول الدفعات لكلّ دورة حضورية

| الدورة | الإجمالي | حجز المقعد | الدفعة 2 | الدفعة 3 |
|---|---|---|---|---|
| أساسيات التعليق | 218 د.أ | **50 د.أ** | 84 د.أ | 84 د.أ |
| المذيع المحترف | 250 د.أ | **50 د.أ** | 100 د.أ | 100 د.أ |
| فن الخطابة | 180 د.أ | **50 د.أ** | 65 د.أ | 65 د.أ |

**القاعدة البرمجية:**
```ts
const DEPOSIT_JOD = 50;                          // ثابت لكلّ الدورات الحضورية
function splitInstallments(totalJOD: number) {
  const rest = totalJOD - DEPOSIT_JOD;
  const each = Math.round(rest / 2);
  return [DEPOSIT_JOD, each, rest - each];       // الفرق يذهب للأخيرة
}
```

**⛔ ولا تكتب المبالغ يدوياً لكلّ دورة** — تُحسب من الإجمالي.

## 7.2 · ما يُحصَّل إلكترونياً

| النمط | المعروض | يُحصَّل الآن |
|---|---|---|
| مباشر تفاعلي | $150 | **$150** |
| حضوري — أساسيات | 218 د.أ | **$71** *(= 50 د.أ)* |
| حضوري — المذيع | 250 د.أ | **$71** *(= 50 د.أ)* |
| حضوري — الخطابة | 180 د.أ | **$71** *(= 50 د.أ)* |

```ts
jodToChargeUSD(50) → Math.ceil(50 × 1.41) = 71
```

**⛔ ومبلغ التحصيل هو 50 ديناراً دائماً — لا الإجمالي.**

## 7.3 · في صفحة الدفع

### النمط المباشر التفاعلي

```

دفعة واحدة كاملة

```
بلا منتقي خطط.

### النمط الحضوري

```

│  إجمالي الدورة            218 ديناراً        │
│  ─────────────────────────────────────────  │
│  تدفع الآن                 50 ديناراً        │
```

**والسطر التوضيحي الإلزامي أسفله:**

> تدفع الآن **50 ديناراً** لتثبيت مقعدك. وتتواصل معك مستشارتك لترتيب الدفعتين الباقيتين أثناء الدورة — تحويلاً أو نقداً.

**⛔ ولا تذكر رقم حساب بنكي في الموقع.** ترتيب الدفعات يتمّ مع المستشارة.

## 7.4 · بنية الطلب

```ts
interface Order {
  id: string;                       // KS-ORD-2026-0142
  sessionId: string;
  courseSlug: string;
  cohortId: string;
  mode: 'onsite' | 'live';
  customer: { firstName; lastName; email?; phone; country; city? };
  totalJOD: number;                 // 218
  plan: 'full' | 'deposit';
  paidJOD: number;                  // 50
  remainingJOD: number;             // 168
  status: 'paid_full' | 'deposit_paid' | 'partially_paid' | 'completed' | 'refunded';
  installments: {
    seq: 1 | 2 | 3;
    amountJOD: number;
    method: 'stripe' | 'bank_transfer' | 'cash';

```

**عند نجاح الدفع:** الدفعة الأولى `method:'stripe'` و`paidAt` مملوء. والثانية والثالثة `paidAt: null` تنتظر التسجيل اليدوي.

# القسم 11 · قائمة الفحص

## قبل الإطلاق — بمفاتيح الاختبار
- [ ] **لا وجود لـ`jod` في أيّ استدعاء لسترايب** — ابحث في الكود
- [ ] `CHARGE_CURRENCY = 'usd'` ثابت ولا يُمرَّر متغيّراً
- [ ] **البيان الإلزامي يظهر فوق زرّ الدفع** في كلّ سعر معروض بالدينار
- [ ] البيان يظهر أيضاً في بريد التأكيد وشاشة النجاح
- [ ] `toMinorUSD(776)` = `77600` — تحقّق بعملية حقيقية
- [ ] الدفع بمبلغ صغير ينجح وتصل الشاشة الصحيحة
- [ ] **افتح `success_url` يدوياً بلا دفع** ← لا يُمنح مقعد
- [ ] الـWebhook يستقبل `raw body` والتوقيع يُتحقَّق منه
- [ ] إرسال الحدث مرّتين ← **طلب واحد لا اثنان**
- [ ] المقعد يُنقص مرّة واحدة فقط
- [ ] دفعة نفدت مقاعدها ← لا تُنشأ جلسة، وتظهر البديلة
- [ ] إلغاء من صفحة سترايب ← يعود لصفحة الدفع والحجز يُحرَّر
- [ ] انتهاء المهلة ← الحجز يُحرَّر تلقائياً
- [ ] بريد التأكيد وواتساب والإشعار الداخلي تصل
- [ ] لوحة الإدارة محمية وتسجّل الدفعات اليدوية

## قبل التحويل لمفاتيح الإنتاج
- [ ] `STRIPE_WEBHOOK_SECRET` الإنتاجي مضبوط
- [ ] رابط الـWebhook مسجَّل في لوحة سترايب
- [ ] عملية حقيقية بمبلغ صغير ثمّ استرداد — واختبر `charge.refunded`
- [ ] الفاتورة تظهر باسم الكيان الصحيح
- [ ] الشروط والأحكام مُحدَّثة بذكر الكيانين
