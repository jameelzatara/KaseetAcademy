### نقاط تقنية إلزامية

1. **`og:image:width` و `height` مش رفاهية.** بدونهم واتساب وفيسبوك بيعرضو كرت صغير بأول مشاركة، وبعد ما يعملو fetch للصورة يكبّروه. حضورهم = كرت كبير من أول ثانية.
2. **الصورة لازم تكون متاحة بدون تسجيل دخول.** لو الموقع لسا محمي بباسورد على Replit، المعاينة رح تفضل فاضية. اختبر برابط incognito.
3. **واتساب بيعمل cache قوي.** بعد أي تعديل على الصورة أو الميتا، امسح الكاش من:
   - Facebook Sharing Debugger → `developers.facebook.com/tools/debug` → اضغط **Scrape Again**
   - أو غيّر اسم الملف (`masar-elami-v2.jpg`) — أسرع حل عملي
4. **حجم الصورة:** تحت 300KB. واتساب بيسكّر عند الملفات الكبيرة وبيعرض بدون صورة.
5. **JPEG مش PNG** لصورة فيها تدرجات — نفس الجودة بثلث الحجم.

### للصفحات التانية
نفس البلوك بالضبط، بس بدّل: `og:url`, `og:title`, `og:description`, `og:image`.
اعمل الميتا تاجز **كومبوننت واحد** بياخذ props، لا كود مكرر بكل صفحة.

# 2 · صورة المعاينة 1200×630

## طريقة التوليد المقترحة (الأدق)

اعمل route داخلي `/_og/masar-elami` يرندر div بمقاس **1200×630 ثابت**، وبعدها اسكرين شوت بـPlaywright واحفظه كملف ستاتيك:

```js
// scripts/gen-og.js
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage({
    viewport: { width: 1200, height: 630 },
    deviceScaleFactor: 2   // للحدة
  });
  await page.goto('http://localhost:3000/_og/masar-elami', { waitUntil: 'networkidle' });
  await page.screenshot({ path: 'public/og/masar-elami.jpg', type: 'jpeg', quality: 88 });
  await browser.close();
})();
```

**ليش هذي الطريقة:** المتصفح يرندر تشكيل العربي (الحروف المتصلة) صح مية بالمية. أي توليد للصورة من خارج المتصفح بيكسر العربي — انتبه لهاي النقطة تحديداً.

## مواصفات التصميم

## 3.3 · تحذيرات مهمة — اقرأها قبل التنفيذ

**١. ممنوع تضيف `offers` بسعر وهمي.**
جوجل يشترط تطابق البيانات المنظّمة مع المحتوى الظاهر. الأسعار حالياً على الصفحة `—`. لو حطيت سعر بالـschema وهو مش ظاهر بالصفحة، هاد **مخالفة** وبيسبب رفض الـrich result أو عقوبة يدوية. أضِف البلوك التالي **فقط بعد ما ينزل السعر الحقيقي على الصفحة**:

```json
"offers": {
  "@type": "Offer",
  "price": "PRICE",
  "priceCurrency": "JOD",
  "category": "Paid",
  "availability": "https://schema.org/InStock",
  "url": "https://DOMAIN.com/masar-elami#enroll"
}
```

**٢. نفس القاعدة على `aggregateRating`.**
ما تضيف تقييمات ونجوم إلا لو في تقييمات حقيقية معروضة على الصفحة نفسها. التقييمات المفبركة بالـschema من أسرع الطرق لعقوبة يدوية من جوجل.

**٣. `FAQPage` schema — أولوية منخفضة.**
جوجل قلّص ظهور نتائج الـFAQ منذ 2023 وصار محصوراً بمواقع حكومية وصحية معتمدة. إضافته ما تضر بس ما تتوقع منها ظهور. لا تصرف عليها وقت الآن.

**٤. اختبر قبل ما تسلّم:**
- `search.google.com/test/rich-results` — يعطيك أخطاء الـschema
- `validator.schema.org` — يتحقق من صحة البنية
- Google Search Console → Enhancements → بعد الفهرسة

# 4 · رقم واتساب (Task #54)

**الرقم مش موجود عندي، ولا أقدر أخترعه — لازم وجيز يبعته.**
وقت ما يوصل، نفّذ التالي:

## 4.1 · خزّنه بمكان واحد

```env
# .env
NEXT_PUBLIC_WHATSAPP=962790000000
```

```js
// lib/config.js
export const WHATSAPP = process.env.NEXT_PUBLIC_WHATSAPP;
export const waLink = (msg) =>
  `https://wa.me/${WHATSAPP}?text=${encodeURIComponent(msg)}`;
```

استخدم `waLink()` بكل مكان. **ممنوع** يتكرر الرقم مكتوباً بأكثر من ملف — لأنه بيتغير مرة وبتضل نسخ قديمة شغالة.

## 4.2 · صيغة الرقم — أشيع خطأ بهاد الموضوع

الرقم الأردني `0790 000 000` يتحول لـ:

```
962790000000        ✅ صح
```

| غلط | ليش |
|---|---|
| `+962790000000` | علامة `+` تكسر الرابط |
| `9620790000000` | الصفر بعد كود الدولة لازم يُحذف |
| `962 79 000 0000` | المسافات تكسر الرابط |
| `00962790000000` | `00` تُستبدل بكود الدولة، ما تُضاف قبله |

**القاعدة:** كود الدولة `962` + الرقم بلا الصفر الأول + بلا `+` وبلا مسافات وبلا شرطات.

## 4.3 · الرسالة المُعبّأة مسبقاً

خلّيها مختلفة بكل صفحة، عشان المستشارة تعرف من وين جاي العميل:

```js
// صفحة ماستركلاس الإعلام
waLink('مرحبا، بستفسر عن ماستركلاس الإعلام')

// صفحة ماستركلاس التعليق الصوتي
waLink('مرحبا، بستفسر عن ماستركلاس التعليق والأداء الصوتي')

// الصفحة الرئيسية
waLink('مرحبا، بستفسر عن برامج كاسيت أكاديمي')
```

## 4.4 · تفاصيل تنفيذ

```html
<a href="..." target="_blank" rel="noopener noreferrer">
```
- `rel="noopener noreferrer"` إلزامي أمنياً على أي `target="_blank"`
- ضيف تتبّع الحدث: `onClick` → `gtag('event','whatsapp_click',{page:'masar-elami'})` — عشان تعرف أي صفحة تجيب استفسارات فعلاً

# 5 · نظام ألوان الخلفيات والطبقات

> **هذا القسم هو حل المشكلة الأساسية.** المشكلة مش بلون معيّن — المشكلة إنه ما في **مصدر واحد للحقيقة**، فكل صفحة تتبني بطبقات مختلفة والنتيجة تتفكك. الحل: التوكنز التالية تصير المرجع الوحيد، وأي لون مكتوب hardcoded بالكود يُحذف ويُستبدل بتوكن.

## 5.1 · التوكنز — انسخها كما هي في `:root`

```css
:root{
  /* ===== خلفيات كحلية ===== */
  --bg-canvas:  #12192A;   /* أغمق طبقة — خلف كل شي */
  --bg-1:       #161E2B;   /* القسم الأساسي */
  --bg-2:       #1A2332;   /* القسم البديل (alternate) */

  /* ===== أسطح الكروت — الكحلي الفاتح ===== */
  --surface-1:  #242F40;   /* الكرت الافتراضي */
  --surface-2:  #2C374B;   /* كرت مرفوع · hover · كرت داخل كرت */
  --surface-3:  #35425A;   /* أعلى مستوى — استخدام نادر جداً */

  /* ===== خلفيات كريمية ===== */
  --cream-1:    #F6F2E9;   /* القسم الكريمي */
  --cream-2:    #FFFFFF;   /* الكرت فوق الكريمي */
  --cream-3:    #EDE6D8;   /* حقل غائر (inset) فوق الكريمي */

  /* ===== النصوص ===== */
  --text-1:     #FFFFFF;   /* على الكحلي */
  --text-2:     #C4CEDD;
  --text-3:     #9AA6B8;
  --text-4:     #76839A;
  --ink-1:      #18202F;   /* على الكريمي */
  --ink-2:      #56617A;
  --ink-3:      #7B8496;

  /* ===== الذهبي ===== */
  --gold:       #FFC107;   /* على الكحلي فقط */
  --gold-ink:   #8A6200;   /* الذهبي كنص على الكريمي */
  --gold-soft:  rgba(255,193,7,.10);
  --gold-line:  rgba(255,193,7,.28);

  /* ===== وجيز ===== */
  --teal:       #1E7A85;

  --teal-line:  rgba(30,122,133,.48);

  --line-cream: rgba(24,32,47,.10);      /* على الكريمي */

  /* ===== الظلال — ثلاثة مستويات فقط ===== */
  --sh-1: 0 2px 8px rgba(0,0,0,.18);     /* شرائح */
  --sh-2: 0 12px 34px rgba(0,0,0,.28);   /* كرت عند hover */

}
```

## 5.2 · القاعدة الذهبية للطبقات

**الكرت لازم يكون درجة واحدة أفتح من القسم اللي هو فيه. ممنوع كرت بنفس لون خلفيته.**

| القسم | الكرت | الكرت الداخلي |
|---|---|---|
| `--bg-1` | `--surface-1` | `--surface-2` |
| `--bg-2` | `--surface-1` | `--surface-2` |
| `--cream-1` | `--cream-2` (أبيض) | `--cream-3` |

كلاسات جاهزة:

```css
.sec--dark  { background: var(--bg-1); color: var(--text-1); }
.sec--alt   { background: var(--bg-2); color: var(--text-1);
              border-block: 1px solid var(--line-1); }
.sec--cream { background: var(--cream-1); color: var(--ink-1); }

.card { background: var(--surface-1); border: 1px solid var(--line-1);
        border-radius: 14px; transition: border-color .25s, transform .25s; }
.card:hover { background: var(--surface-2); border-color: var(--gold-line);
              transform: translateY(-3px); box-shadow: var(--sh-2); }

/* الكريمي يقلب كل شي — لازم override صريح */
.sec--cream .card         { background: var(--cream-2); border-color: var(--line-cream); }
.sec--cream .card:hover   { background: var(--cream-2); border-color: var(--gold-ink); }
.sec--cream h2, .sec--cream h3, .sec--cream h4 { color: var(--ink-1); }
.sec--cream p             { color: var(--ink-2); }
.sec--cream .accent       { color: var(--gold-ink); }  /* لا --gold */
```

## 5.3 · تحذير حاسم على الكريمي

**`#FFC107` كنص على خلفية كريمية أو بيضاء = نسبة تباين 1.6:1 — غير مقروء ومخالف لمعايير الوصولية (الحد الأدنى 4.5:1).**

| الحالة | الصح |
|---|---|
| نص ذهبي على كريمي | `--gold-ink` (#8A6200) — تباين 5.9:1 ✅ |
| زر ذهبي على كريمي | خلفية `--gold` + نص `#1A1206` ✅ |
| حدود ذهبية على كريمي | `--gold-ink` بشفافية 40% ✅ |
| نص `--gold` على كريمي | ❌ ممنوع |

## 5.4 · إيقاع الأقسام

```
dark → alt → dark → CREAM → dark → alt → dark
```

**قواعد الكريمي:**
- **قسم كريمي واحد بالصفحة كحد أقصى** — اتنين يكسرو الهوية الكحلية
- ممنوع قسمين كريميين ورا بعض
- ممنوع الكريمي أول قسم أو آخر قسم — لازم يكون محاصر بكحلي من الجهتين

**وين نحطه؟** توصيتي: **قسم الالتحاق والأسعار.**
الأقسام الفاتحة تُقرأ كـ"رسمية وموثوقة" — وهاي بالضبط الإحساس المطلوب عند لحظة قرار الدفع. وكمان بتعطي راحة بصرية بمنتصف صفحة طويلة كحلية.

## 5.5 · الطبقات المحيطة — الشبكة والضو والتمويجات

الثلاثة `position: fixed`, `z-index: 0`, `pointer-events: none`, وخلف كل المحتوى:

## 5.6 · النيون — القاعدة الحاسمة

```css
.neon{
  border: 1px solid var(--gold);
  box-shadow:
    0 0 0 1px rgba(255,193,7,.55),
    0 0 22px rgba(255,193,7,.16),
    var(--sh-3);
}
```

**عنصر نيون واحد بكل شاشة. لا أكثر.**

النيون وظيفته يقول "هذا هو الشي المهم". لو كل شي يلمع، ما في شي يلمع — وهاد بالضبط سبب الإحساس بالفوضى الحالي.

| ✅ استخدمه على | ❌ لا تستخدمه على |
|---|---|
| الخطة المميزة بقسم الأسعار | كل الكروت |
| كرت مشروع التخرّج | الشرائح والبادجز |
| الزر الأساسي (CTA) | حدود الأقسام |
| — | أكثر من عنصر بنفس الشاشة |

## 5.7 · الممنوعات — راجعها قبل ما تسلّم

1. ❌ أكثر من `glow` واحد بالصفحة
2. ❌ كرت بنفس لون القسم اللي هو فيه
3. ❌ نيون على أكثر من عنصر بالشاشة الواحدة
4. ❌ `#FFC107` كنص على كريمي أو أبيض
5. ❌ الشبكة داخل الكروت
6. ❌ تمويجات بمنتصف الصفحة
7. ❌ أكثر من 3 مستويات ارتفاع (surface) بنفس الشاشة
8. ❌ أي لون hex مكتوب مباشرة بالكود — **كله لازم يمر بتوكن**

## 5.8 · خطوة التنظيف الإلزامية

قبل ما تعتبر المهمة خلصت:

```bash
# ابحث عن كل الألوان الـhardcoded واستبدلها بتوكنز
grep -rn "#[0-9A-Fa-f]\{6\}" src/ --include="*.css" --include="*.tsx" --include="*.jsx"
grep -rn "rgba(" src/ --include="*.css" --include="*.tsx" --include="*.jsx"
```

كل نتيجة تظهر **برا** بلوك `:root` لازم تُستبدل بتوكن. هاي الخطوة هي اللي فعلياً تحل المشكلة — التوكنز بلا تنظيف بتصير طبقة زيادة لا حل.

## 5.9 · التسليم المطلوب

اعمل صفحة `/_styleguide` تعرض:
- كل التوكنز كمربعات ملوّنة مع أسمائها وقيمها
- مثال قسم كحلي · قسم بديل · قسم كريمي
- كرت عادي · كرت hover · كرت نيون
- الطبقات الثلاثة المحيطة كل واحدة لحالها ثم مجتمعة

هاي الصفحة تصير المرجع لأي صفحة جديدة، وتمنع تكرار المشكلة.
