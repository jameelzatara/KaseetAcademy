# ٣ · الخلفية — النقش الورقي

## التوكنز الجديدة

```css
--paper:        #F4EFE4;   /* بيج ورقي */
--paper-2:      #EFE8DA;   /* بيج أغمق للتدرّج الحدودي */
--paper-dot:    rgba(122, 88, 26, .16);   /* نقطة بنّية */
--paper-line:   rgba(122, 88, 26, .10);   /* حدود البطاقات */
--paper-ink:    #201A12;   /* عنوان */
--paper-ink-2:  #5A5145;   /* شرح */
--paper-ink-3:  #8B8073;   /* أرقام وشارات */
```

## النقش

```css
.mc-outcomes--paper {
  position: relative;
  background-color: var(--paper);
  isolation: isolate;
}

.mc-outcomes--paper::before {
  content: '';
  position: absolute;
  inset: 0;
  z-index: -1;
  background-image:
    radial-gradient(var(--paper-dot) 1.3px, transparent 1.3px),
    radial-gradient(var(--paper-dot) 1.3px, transparent 1.3px);
  background-size: 24px 24px;
  background-position: 0 0, 12px 12px;
  -webkit-mask-image: radial-gradient(115% 85% at 50% 8%, #000 45%, transparent 100%);
          mask-image: radial-gradient(115% 85% at 50% 8%, #000 45%, transparent 100%);
}
```

**لماذا شبكتان بإزاحة 12px:** تعطي شبكة نقاط متعامدة الأقطار لا صفوفاً مستقيمة — أقرب إلى نقش ورق وأقلّ حِدّة من شبكة واحدة.

**ولماذا الـ`mask`:** النقاط تتلاشى عند الحواف فلا تصطدم بحدود القسم. **هذا ما يمنع الجمود** — بلا القناع تبدو الخلفية جدولاً.

## الانتقال من الداكن وإليه

```css
.mc-outcomes--paper::after {
  content: '';
  position: absolute;
  left: 0; right: 0; bottom: 0;
  height: 96px;
  z-index: -1;
  background: linear-gradient(to bottom, transparent, var(--paper-2));
}
```
وشريط بارتفاع `72px` فوق القسم يتدرّج من `--canvas` إلى `--paper`. ⛔ **لا حدّ حادّ بين الداكن والفاتح.**

**⛔ تنبيه:** إن كان في صفحة الإعلام بلوك محفظة كريمي أيضاً، فسيصير في الصفحة قسمان فاتحان. لا يجوز أن يتلاصقا — يفصلهما بلوك داكن واحد على الأقلّ.

# ٤ · البطاقات على الخلفية الفاتحة

```css
background: rgba(255,255,255,.62);
border: 1px solid var(--paper-line);
border-radius: 12px;
backdrop-filter: blur(2px);
```

بطاقة نصف شفّافة يظهر النقش خلفها باهتاً — أفضل من بطاقة بيضاء صلبة تقطع النقش.

| العنصر | اللون |
|---|---|
| الرقم `01`–`04` | `--paper-ink-3` · وأصغر من العنوان |
| عنوان البطاقة | `--paper-ink` |
| الشرح | `--paper-ink-2` |
| الشارة | خلفية `rgba(122,88,26,.08)` + نصّ `--paper-ink-2` |
| أيّ ذهبي | **`--gold-ink #8A6200`** ⛔ لا `#FFC107` |

⛔ **الأرقام لا تسود على العنوان** — الفائدة أوّلاً والترقيم ثانياً.
⛔ **الأيقونات `lucide-react`** إن استُخدمت · بلا إيموجي.
⛔ **الأرقام بـPoppins** والنصّ بـGE SS Two / Tajawal.

# ٦ · ما ينتظر

**المخرجات الأربعة نفسها.** البلوك جاهز والنصوص الثلاثة معتمدة، لكن بطاقات المخرجات تحتاج محتوى الإعلام.

**قالب كلّ بطاقة:**
```

الشرح:   سطران · ما يُسلَّم أو ما يُقاس · بلا صفات عامّة
```

⛔ **ولا يُنشر البلوك ببطاقات مؤقّتة** — يبقى `outcomes.items` فارغاً والبلوك مخفيّاً حتى تصل.
