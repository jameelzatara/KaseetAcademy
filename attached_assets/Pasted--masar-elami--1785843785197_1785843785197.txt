# `/masar-elami` — نظام الخلفيات فقط
**لا تعدّل أي كرت، ولا نص، ولا تخطيط. الخلفيات وحدها.**

---

## لماذا التعديل السابق لم يُظهر أي فرق

الفرق بين `#161E2B` و `#1A2332` هو **2.45 وحدة L\*** (الإضاءة المدركة). العين البشرية لا تُميّز أقل من ~4 وحدات على مساحات كبيرة. فالتنفيذ كان صحيحاً والقيم كانت خاطئة.

والمشكلة بنيوية: عند هذا العمق (L\* بين 11 و 14) لا يوجد مجال كافٍ لتباين محسوس بين درجتين من نفس اللون. أي درجتَي كحلي غامق ستُنتج النتيجة نفسها.

**الحل: إلغاء مبدأ "لون خلفية لكل قسم".**
بدلاً منه: **لوحة أم واحدة** + **طبقات جو ملوّنة** تتجاوز حدود الأقسام وتتداخل مع ما بعدها. العين تُدرك تغيّر اللون والاتجاه، لا فروقات الإضاءة.

القياس: طبقة ذهبية بشفافية 9% فوق اللوحة الأم تُنتج فرقاً قدره **+7.56 L\*** مع انزياح لوني كامل — أي ثلاثة أضعاف الفرق الحالي.

# 1 · احذف أولاً

قبل أي إضافة، احذف من **كل** الأقسام في `/masar-elami`:

```css
/* احذف هذه من كل قسم */
background: #161E2B;
background: #1A2332;
background-color: #161E2B;
background-color: #1A2332;
```

لا يبقى أي `background` على أي `<section>`. الأقسام تصبح شفافة بالكامل، واللون يأتي من طبقة واحدة تحتها.

# 2 · اللوحة الأم

```css
body{
  background: #0C1219;   /* L* = 5.25 — أعمق من الحالي، ليتيح مجالاً لكل ما فوقه */
}
```

هذه القيمة مقصودة: كل طبقة جو فوقها ستكون مرئية بوضوح. لو بقيت اللوحة عند `#161E2B` فلن يظهر أي أثر للطبقات.

# 3 · بنية الطبقات

كل قسم يحصل على ثلاث طبقات فوق اللوحة الأم:

```css
.sec{
  position: relative;
  background: transparent;      /* إلزامي */
  isolation: isolate;
}

/* المحتوى — فوق كل شيء */
.sec > .wrap{ position: relative; z-index: 3 }

/* الطبقة 1 · الجو اللوني — تتجاوز حدود القسم فتتداخل مع ما بعده */
.sec::before{
  content: "";
  position: absolute;
  inset: -22% -12%;             /* التجاوز هو ما يخلق التداخل */
  z-index: 0;
  pointer-events: none;
}

/* الطبقة 2 · الشكل الهندسي */
.sec > .geo{
  position: absolute;
  inset: 0;
  z-index: 1;
  pointer-events: none;
  overflow: hidden;
}
```

> **`inset: -22% -12%` هو جوهر الحل.** طبقة الجو تخرج عن حدود القسم من الأعلى والأسفل، فتتداخل مع القسم المجاور. هذا التداخل هو ما يُنتج الإحساس بأن الصفحة فضاء واحد مُضاء لا صناديق مرصوفة. **لا تضع `overflow: hidden` على `.sec`** — سيقتل التداخل ويعيدنا للمشكلة الأصلية.

# 4 · اللغة الهندسية — عدسة الكاميرا وإطار البث

المسار الإعلامي يحتاج لغة بصرية خاصة به تُميّزه عن ماستركلاس التعليق الصوتي (الذي يستخدم الموجة الصوتية). اللغة المختارة: **عدسة الكاميرا وإطار التصوير والبث**.

| الشكل | المعنى | القسم |
|---|---|---|
| إطار الثلثين + أقواس الزوايا | إطار الكاميرا | Hero |
| أعمدة الشاشة | أشرطة البث | الشجرة |
| دائرتان متقاطعتان | استوديو ∩ بُعد | أسلوب التعلّم |
| نقاط الهاف‑تون | الطباعة والصحافة | ما ستحققه |
| أقواس البث المتراكزة | إشارة البث | المدربون |
| حدقة العدسة السداسية | فتحة العدسة | الأسعار |
| خطوط المسح | شاشة CRT | المستشارة |
| قوس ذهبي كاسح | الختام | CTA |

**الأنماط المتكرّرة** (CSS خالص، بلا ملفات):

```css
/* أعمدة الشاشة — خطوط رأسية كل 96px */
.geo--columns{
  background-image: repeating-linear-gradient(
    to left, rgba(255,255,255,.030) 0 1px, transparent 1px 96px);
  mask-image: linear-gradient(to bottom, transparent, #000 22%, #000 78%, transparent);
}

/* خطوط المسح — أفقية كل 4px */
.geo--scan{
  background-image: repeating-linear-gradient(
    to bottom, rgba(255,255,255,.022) 0 1px, transparent 1px 4px);
  mask-image: radial-gradient(ellipse 70% 60% at 50% 50%, #000, transparent 72%);
}

/* نقاط الهاف‑تون — للقسم الكريمي فقط */
.geo--halftone{
  background-image: radial-gradient(rgba(24,32,47,.11) 1.1px, transparent 1.2px);
  background-size: 14px 14px;
  mask-image: linear-gradient(to bottom, #000, transparent 65%);
}
```

# 6 · الأرقام المُقاسة

| الطبقة | اللون والشفافية | الناتج فوق اللوحة | فرق الإضاءة |
|---|---|---|---|
| ذهبي | `#FFC107` @ 9% | `#222217` | **+7.56 L\*** |
| تركوازي | `#1E7A85` @ 10% | `#0E1C24` | **+4.29 L\*** |
| أزرق فولاذي | `#3B6FA8` @ 9% | `#101A26` | **+3.80 L\*** |
| أخضر | `#25D366` @ 5% | `#0D1C1D` | **+3.66 L\*** |
| بنفسجي كحلي | `#5B4B8A` @ 8% | `#121722` | **+2.37 L\*** |

للمقارنة: التبادل السابق كان يعطي **+2.45 L\*** بلا أي انزياح لوني. الفرق أن هذه الطبقات تُغيّر **اللون** لا الإضاءة وحدها — وهو ما تُدركه العين فعلاً.

الكرت يبقى ثابتاً في كل الأقسام: `#25303F` (فرق **+14.25 L\*** عن اللوحة)، وعند hover `#2E3A4C`.

# 7 · التحقّق قبل التسليم

- [ ] لا يوجد `background` على أي `<section>` — عدا القسم الكريمي
- [ ] `body` لونه `#0C1219`
- [ ] لا يوجد `overflow: hidden` على أي قسم — عدا الكريمي
- [ ] كل قسم فيه `position: relative` و `isolation: isolate`
- [ ] `.wrap` فيه `z-index: 3`
- [ ] طبقات `.geo` فيها `pointer-events: none`
- [ ] كل `<svg>` فيه `aria-hidden="true"`
- [ ] القسم الكريمي ظاهر فعلاً بحدّيه الذهبيين
- [ ] FAQ بلا شكل هندسي

**اختبار العين:** مرّر الصفحة بسرعة من الأعلى للأسفل. يجب أن تُحسّ بتغيّر مناخ لوني عند كل قسم. إن بدت الصفحة موحّدة، فالسبب أحد اثنين: بقي `background` على الأقسام، أو `body` ليس بالقيمة `#0C1219`.
