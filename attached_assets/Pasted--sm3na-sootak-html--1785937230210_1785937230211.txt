قم بإنشاء/تعديل ملف `sm3na-sootak.html` في كود المشروع ليكون صفحة "استوديو سمعنا صوتك التفاعلي" لأكاديمية كاسيت. يجب أن تتطابق الصفحة تماماً مع الألوان والأنماط البصرية وخلفيات صفحة "المسار الإعلامي" المعتمدة في الموقع، وأن تخلو نهائياً من أي Emojis تعبيرية مع الاعتماد الحصري على مكتبة Lucide Icons.

المتطلبات الدقيقة والتفصيلية:

1. الترويسة وهيدر الموقع (Header):
   - الشعار الرئيسي لأكاديمية كاسيت على اليمين.
   - زر محول العملة `JOD ع.أ` مع قائمة منسدلة صغيرة لاختيار العملات (SAR, AED, KWD, USD).
   - زر الذهابي الرئيسي "ابدأ رحلتك الصوتية" باللون الذهبي/الأصفر (Amber).
   - قائمة الثلاث خطوط (Hamburger Menu): عند الضغط عليها تفتح قائمة جانبية تنزلق بسلاسة (Mobile Drawer Menu) وتقتصر محتوياتها فقط وحصرياً على رابط واحد: "تسجيل الدخول / حسابي" مع زر إغلاق (أيقونة x).

2. قسم الهيرو (Hero Section):
   - استخدام نفس خلفيات وألوان صفحة "المسار الإعلامي" (Dark Navy `#0F172A` / `#0B0F17` مع لمسات ذهبية/كهرمانية Glowing Amber `#F59E0B`).
   - العنوان الرئيسي: "اخفض صوت العالم... وارفع صوت الكاسيت"
   - العنوان الفرعي: "لكل صَوت حكاية... قس قدراتك الصوتية واستلم تقريراً استشارياً من خبراء كاسيت."
   - زر "استكشف" مع أيقونة Lucide (`chevron-down`) ينزل بسلاسة (Smooth Scroll) إلى قسم `#voice-wizard`.
   - شريط الإحصائيات العدادي الزجاجي (Glassmorphism):
     * العداد الأول: 5,000+ طالب مسجل (أيقونة: users)
     * العداد الثاني: 700+ دورة تدريبية (أيقونة: award)
     * العداد الثالث: 8,500+ ساعة تدريب مباشر (أيقونة: clock)
     * تفعيل العد السلس المضمون 60fps بدون أي Lag باستخدام requestAnimationFrame و IntersectionObserver.
     * تذييل الشريط بموجة صوتية ذهبية تمتد بخطين أفقيين على الطرفين الأيمن والأيسر لربط الحواف وإكمال الـ Wave عبر عرض الصفحة بالكامل.

3. استوديو التقييم التفاعلي المبتكر (Realistic Studio Console UX - `#voice-wizard`):
   - تصميم واجهة استوديو صوتي احترافي يحاكي برامج الهندسة الصوتية (DAW Rack Console) بخلفية زجاجية معتمة وأزرار إضاءة نيون ذهبية.
   - الخطوة 1 (المسار والخبرة): بطاقات تفاعلية مبسطة لاختيار نوع الصوت (إعلانات: megaphone، وثائقيات: book-open، دبلجة: clapperboard، رد آلي: phone-call) ومستوى الخبرة.
   - الخطوة 2 (استوديو التسجيل المباشر):
     * زر تسجيل استوديو ضخم متوهج مع أيقونة mic.
     * شاشة معالجة صوتية حية (Real-time Canvas Audio Waveform Visualizer) تعمل بواسطة Web Audio API لعرض الترددات الصوتية أثناء التسجيل.
     * مؤقت زمني عكسي ديجيتال (30 ثانية).
     * مشغل صوتي مدمج لإعادة الاستماع والتأكيد أو إعادة التسجيل (أيقونات: play, square, rotate-ccw).
   - الخطوة 3 (نموذج بيانات مبتكر - Creative Lead Form):
     * حقول إدخال ذكية بتأثير Glow ذهبي عند التركيز (الاسم كامل، رقم الواتساب، البريد الإلكتروني، الدولة).
     * كارت عائم تفاعلي "بطاقة عضوية الاستوديو" (Studio Live Pass) يتحدث فورياً أثناء كتابة الاسم والدولة لإضفاء لمسة ابتكار حية.
     * زر الإرسال "إرسال عينة الصوت للخبراء" مع أيقونة send.
   - عند الإرسال: تشفير التسجيل إلى Base64 DataURL وإرسال كافة البيانات فوراً إلى رابط Google Apps Script Webhook مع إظهار شاشة نجاح متحرّكة بأيقونة check-circle-2.

4. قسم الخبراء والتقييم (Evaluators Section):
   - كروت استشارية بخلفيات مظللة تعرّف بخبراء التقييم الصوتي بأيقونات Lucide (headphones, mic, star).
